# Сышэн

PWA для китайского на русском: карточки с интервалами, шесть нейронных голосов путунхуа и свои списки слов.

Официальный HSK 1 (150 слов, программа 2012) уже внутри. Отдельно — минимальные пары на тоны: слышишь слог и выбираешь контур, без перевода на кнопках.

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

Приложение откроется на `http://localhost:5173`. API слушает порт из `PORT` (по умолчанию 8787).

## Переменные

| Имя | Зачем |
| --- | --- |
| `ANYMODEL_API_KEY` | Ключ [AnyModel](https://anymodel.org/). Только на сервере, в браузер не попадает. |
| `ANYMODEL_MODEL` | Модель объяснений. По умолчанию `ag/gemini-2.5-flash-lite`. |
| `PORT` | Порт сервера. На Railway задаётся сам. |

Без ключа карточки и озвучка работают, кнопки «Объяснить» и «Заполнить по иероглифу» отвечают, что ИИ не подключён.

Озвучка — нейронные голоса путунхуа (Сяосяо, Сяои, Юньси, Юньцзянь, Юньян, Юнься). Если сервис голоса молчит, фраза уходит в речевой синтез устройства.

## Сборка

```bash
npm run build
npm start
```
